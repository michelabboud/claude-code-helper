# Glossary

## A
**Agent** - An autonomous AI system that can take actions
**Agent SDK** - Framework for building autonomous agents programmatically
**Artifact** - Created content (docs, code) that renders in Claude.ai

## C
**CLAUDE.md** - Project memory file that loads automatically
**Compact** - Reduce conversation history to save tokens
**Context Window** - Amount of text Claude can process at once

## H
**Hook** - Automated script that runs at specific workflow points

## M
**MCP** - Model Context Protocol, standard for connecting to external tools
**MCP Server** - Service that provides tools via MCP

## P
**Plugin** - Bundled package of commands, agents, skills, and hooks
**Progressive Disclosure** - Showing info gradually as needed

## S
**Skill** - Portable expertise that Claude loads on-demand
**Slash Command** - User-triggered shortcut (e.g., /help)
**Sub-agent** - Specialized Claude instance for specific tasks

## T
**Tool** - Function Claude can call (Read, Write, Bash, etc.)
