How to Generate New Playgrounds

Ask the project-manager agent to generate playgrounds based on context:

  • "Assess this project" → Health Score Explorer
  • "Plan the next sprint" → Priority Matrix
  • "Is this ready to deploy?" → Risk Heatmap
  • "Show me the tech debt" → Technical Debt Dashboard
  • "How have we improved?" → Score Comparison Timeline
  • "Deep dive into security" → Expert Deep-Dive

Requires playground@claude-plugins-official plugin. Each playground is a self-contained HTML file.
