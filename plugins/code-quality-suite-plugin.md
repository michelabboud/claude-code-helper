# Code Quality Suite Plugin

Comprehensive quality assurance with testing, refactoring, and code analysis.

## Components

- QA/Testing Expert Agent
- Code Review Workflow Skill
- Refactoring Strategy Skill
- TDD Workflow Skill
- Code Quality Gate Hook

## Features

- ✅ Automated test generation
- ✅ Code quality gates
- ✅ Refactoring assistance
- ✅ TDD workflow support
- ✅ Code review automation

## Usage

```bash
# Generate tests
/test-generate src/services/user.ts

# Refactor code
/refactor extract-method calculateTotal

# Review code quality
Ask: "Review the code quality of my recent changes"
```
