# Security Hardening Plugin

Complete security solution for scanning, hardening, and compliance.

## Components

- Security Expert Agent
- Dependency Management MCP
- Security Scan Hook
- Vulnerability Remediation Skill

## Features

- ✅ Automated security scanning
- ✅ Dependency vulnerability detection
- ✅ Secret detection and prevention
- ✅ Compliance checking
- ✅ Security best practices enforcement

## Usage

```bash
# Run security audit
/security-audit

# Fix vulnerabilities
Ask: "Fix the security vulnerabilities in my dependencies"

# Scan for secrets
Ask: "Check for exposed secrets in my code"
```
